# Superseded incident-risk direction

Archived on 2026-11-15 at the owner's request. Ephorate is now planned as a review capacity simulator delivered as a local Python CLI and GitHub Action.

The owner changed direction because incident-risk scoring faces established competitors and depends on incident data the project does not have. The named competitor findings are owner-provided market context, not an independently verified competitive survey.

This folder preserves the former `PROJECT_PLAN.md`, the 2026-11-14 Milestone 0 handoff, and the pitch PDF without deleting or changing their contents. They are historical references, not implementation instructions. Their infrastructure, dependencies, product claims, and roadmap do not govern the current project.

The active rules, plan, and next handoff live at the repository root and under `agent_instruction/`. The original downloaded `ephorate.zip` and `ephorate/` starter remain at the root as historical references; do not use their nested plan as the active one.

The interrupted implementation produced 19 uncommitted scaffold files. With the owner's explicit approval, those agent-created drafts were moved to temporary recovery storage outside the repository. No product implementation from that run was committed or retained as the new skeleton.

`jellyfish.pdf` remains in the public repository by the owner's explicit decision. Removing the current file in the future would not remove earlier Git history; no history rewriting was performed.
